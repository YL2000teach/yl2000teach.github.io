# מצגת חיה: הוראות הקמה

## מה יש בתיקייה

| קובץ | תפקיד |
| --- | --- |
| index.html, present.js | המצגת. נפתחת במחשב המקרן. |
| vote.html, vote.js | דף ההצבעה לטלפון. לשם מוביל קוד ה־QR. |
| questions.js | תוכן השאלות. זה הקובץ שמשנים לכל שיעור. |
| style.css | צבעים, גופנים ופריסה. כל הצבעים מוגדרים בראש הקובץ. |
| config.js | חיבור ל־Firebase וכתובת המייל של המנחה. |
| store.js | שכבת הנתונים. אין צורך לגעת בו. |
| database.rules.json | כללי האבטחה שמדביקים ב־Firebase. |
| vendor/qrcode.js | ספריית QR (רישיון MIT). |

## שלב 0: בדיקה במצב הדגמה (בלי Firebase)

כל עוד `FIREBASE_CONFIG` ב־config.js הוא `null`, המערכת עובדת מקומית.
אחרי העלאה ל־GitHub Pages, פותחים שתי לשוניות באותו דפדפן:
- `https://yam-data.com/live/?s=demo`
- `https://yam-data.com/live/vote.html?s=demo`

בלשונית המצגת יש כפתור "הדמיית 20 הצבעות" לבדיקת המראה.

## שלב 1: פרויקט Firebase (פעם אחת, מחשבון Google הפרטי)

1. נכנסים ל־console.firebase.google.com ויוצרים פרויקט חדש. אפשר לוותר על Google Analytics.
2. **Build > Realtime Database > Create database.** בוחרים מיקום באירופה (europe-west1) ומתחילים ב־locked mode.
3. בלשונית **Rules** מדביקים את התוכן של database.rules.json. מחליפים את שתי ההופעות של `TEACHER_EMAIL_HERE` בכתובת ה־Gmail שלך, ולוחצים Publish.
4. **Build > Authentication > Get started.** בלשונית Sign-in method מפעילים שתי אפשרויות: **Anonymous** (לתלמידים) ו־**Google** (לך).
5. **Authentication > Settings > Authorized domains:** מוסיפים `yam-data.com`.
6. **Project settings > Your apps > סמל `</>`:** רושמים אפליקציית Web ומעתיקים את האובייקט `firebaseConfig`. חשוב לעשות את זה אחרי שלב 2, כדי שהשדה `databaseURL` יופיע בו.

## שלב 2: חיבור הקוד

ב־config.js:
- מדביקים את האובייקט במקום `null`.
- ממלאים את `TEACHER_EMAIL` באותה כתובת שהוכנסה לכללים.

הפרטים ב־firebaseConfig אינם סודיים. ההגנה על הנתונים נעשית דרך הכללים.

## שלב 3: העלאה

מעלים את התיקייה `live` למאגר של האתר. הכתובות יהיו:
- מצגת: `https://yam-data.com/live/?s=class1`
- הצבעה: נוצרת אוטומטית בקוד ה־QR.

הפרמטר `s` הוא שם המפגש. שם חדש מתחיל מפגש נקי, ושם קיים ממשיך מאותו מקום.

## בשיעור

1. פותחים את המצגת ולוחצים "התחברות מנחה" (חשבון Google).
2. מקשים: חצים למעבר בין שאלות, O לפתיחה וסגירה, R להצגה והסתרה של תוצאות, F למסך מלא.
3. מעבר לשאלה פותח אותה להצבעה, והתוצאות מוסתרות עד שלוחצים R.
4. איפוס: לוחצים פעמיים תוך 3 שניות.

## בדיקה לפני השיעור הראשון

- להתחבר מהטלפון לרשת של בית הספר ולוודא שדף ההצבעה נטען. ייתכן שהרשת חוסמת את Firebase.
- תלמיד יכול להצביע פעם אחת לכל שאלה מכל דפדפן, ולשנות את התשובה עד שההצבעה נסגרת. מי שיפתח חלון גלישה בסתר יוכל להצביע שוב. זו מגבלה ידועה של הצבעה בלי הרשמה.
